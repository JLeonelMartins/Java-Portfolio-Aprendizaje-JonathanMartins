## 🧠 Programación Orientada a Objetos (POO)
Implementaciones que aplican los fundamentos de la **POO en Java**, incluyendo clases, objetos, constructores y listas dinámicas.

### 📘 `AgendaElectronica.java`
Simula una agenda digital con funciones para:
- Cargar contactos (nombre, apellido, DNI, teléfono, dirección)
- Buscar registros por DNI  
- Mostrar los datos encontrados desde consola  

### 🎟️ Sistema de Reserva de Asientos
Incluye las clases:
- `ReservaAsientos.java`
- `Ticket.java`
- `Cliente.java`

Permite:
- Mostrar un mapa de asientos (matriz 10x10)  
- Reservar asientos disponibles  
- Generar tickets con datos del cliente  
- Guardar las reservas en una lista dinámica (`ArrayList<Ticket>`)

Conceptos aplicados:
- Encapsulamiento  
- Constructores con y sin parámetros  
- Composición entre clases  
- Listas dinámicas y validaciones de datos

## 🎄 Desafío Navideño
Archivo: `DesafioNavidenio.java`

Un pequeño desafío de lógica en el que:
- Se genera una matriz 4x4 con emojis aleatorios  
- El usuario debe adivinar cuántas veces aparece un emoji elegido  
- El sistema evalúa el resultado y muestra si acertó 🎅  

Conceptos aplicados:
- Generación aleatoria (`Random`)
- Matrices bidimensionales
- Comparación de cadenas (`equals`)
- Entrada de usuario (`Scanner`)
